# Public problem definition

Build a small customer-level classifier of a supplied fixed-horizon churn label
using early invoice/product histories. One invoice row is not one customer.
The public inputs are fictional and generated by `src.generate_demo_data`.

This is an independent portfolio adaptation of a private technical exercise.
The original prompt and customer data are not redistributed. The public demo
illustrates the workflow; it does not recreate measured business outcomes.

The labeled file contains `noise` (True = churn). The scoring file has no label.
The export uses `FK_DWH_CUSTOMERS` and integer `Predictions` (0/1), with exact
customer coverage. No original individual prediction is distributed.
