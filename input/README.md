# Generated inputs

Run `python -m src.generate_demo_data` from the repository root. This creates
`training.csv`, `validation.csv` and a synthetic `case_study.ipynb` describing
the demo. All three are generated locally and excluded from Git.

The notebook filename is a provenance-interface convention, not the original
exercise. No original brief, customer records or individual predictions are
distributed. Generated customer identifiers start with `SYN-`.
